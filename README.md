# Fitness Club — React Website

A responsive fitness-club website concept built with **React, Vite, and CSS**. It demonstrates component-based page structure, reusable UI sections, and responsive design.

**[Live demo](https://fitness-club-rouge-five.vercel.app/)**

![Fitness Club website preview](./screenshot-1.png)

## What I built

- Responsive landing page and navigation
- Reusable React components for the hero, statistics, trainers, and team gallery
- Trainer cards and image-based sections
- Modular CSS for page layouts and styling

## Tech stack

**React 19** · **JavaScript** · **Vite 7** · **CSS**

## Project structure

```text
src/
  components/
    Navbar.jsx
    Hero.jsx
    Stats.jsx
    Trainers.jsx
    Team.jsx
    Footer.jsx
  styles/
```

## Run locally

```bash
npm install
npm run dev
```

Build / lint:

```bash
npm run build
npm run lint
```

## Scope

This is a **frontend demonstration project**, not a working gym membership or booking platform. Trainer profiles and business statistics are illustrative sample content.
